# \

getMyShortDescription\
\
Use this method to get the current bot short description for the given user language. Returns [BotShortDescription](https://core.telegram.org/bots/api#botshortdescription)\
 on success.\
\
| Parameter | Type | Required | Description |\
| --- | --- | --- | --- |\
| language_code | String | Optional | A two-letter ISO 639-1 language code or an empty string |\
\
