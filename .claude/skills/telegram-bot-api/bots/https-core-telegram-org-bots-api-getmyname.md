# \

getMyName\
\
Use this method to get the current bot name for the given user language. Returns [BotName](https://core.telegram.org/bots/api#botname)\
 on success.\
\
| Parameter | Type | Required | Description |\
| --- | --- | --- | --- |\
| language_code | String | Optional | A two-letter ISO 639-1 language code or an empty string |\
\
