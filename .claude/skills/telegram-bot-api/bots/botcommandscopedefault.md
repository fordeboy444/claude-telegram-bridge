# botcommandscopedefault

BotCommandScopeDefault

Represents the default [scope](https://core.telegram.org/bots/api#botcommandscope)
 of bot commands. Default commands are used if no commands with a [narrower scope](https://core.telegram.org/bots/api#determining-list-of-commands)
 are specified for the user.

| Field | Type | Description |
| --- | --- | --- |
| type | String | Scope type, must be _default_ |
