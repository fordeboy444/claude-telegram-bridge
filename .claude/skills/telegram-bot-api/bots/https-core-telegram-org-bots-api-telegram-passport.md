# [](Https://Core.Telegram.Org/Bots/Api#Telegram Passport)\

Telegram Passport\
\
**Telegram Passport** is a unified authorization method for services that require personal identification. Users can upload their documents once, then instantly share their data with services that require real-world ID (finance, ICOs, etc.). Please see the [manual](https://core.telegram.org/passport)\
 for details.\
