# do i need a local bot api server

Do I need a Local Bot API Server

The majority of bots will be OK with the default configuration, running on our servers. But if you feel that you need one of [these features](https://core.telegram.org/bots/api#using-a-local-bot-api-server)
, you're welcome to switch to your own at any time.
