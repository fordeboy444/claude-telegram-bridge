# chatmemberleft

ChatMemberLeft

Represents a [chat member](https://core.telegram.org/bots/api#chatmember)
 that isn't currently a member of the chat, but may join it themselves.

| Field | Type | Description |
| --- | --- | --- |
| status | String | The member's status in the chat, always “left” |
| user | [User](https://core.telegram.org/bots/api#user) | Information about the user |
