# \

removeChatVerification\
\
Removes verification from a chat that is currently verified [on behalf of the organization](https://telegram.org/verify#third-party-verification)\
 represented by the bot. Returns _True_ on success.\
\
| Parameter | Type | Required | Description |\
| --- | --- | --- | --- |\
| chat_id | Integer or String | Yes | Unique identifier for the target chat or username of the target bot or channel in the format `@username` |\
\
