# august 24 2026

August 24, 2026

**Bot API 10.3**

**Rich Messages**

*   Added the class [RichMessageButton](https://core.telegram.org/bots/api#richmessagebutton)
     representing a button in a [RichMessage](https://core.telegram.org/bots/api#richmessage)
    .
*   Added the class [RichTextButton](https://core.telegram.org/bots/api#richtextbutton)
    .
*   Added the classes [RichBlockButtons](https://core.telegram.org/bots/api#richblockbuttons)
     and [InputRichBlockButtons](https://core.telegram.org/bots/api#inputrichblockbuttons)
    .
*   Added the field _is_compact_ to the classes [RichBlockTable](https://core.telegram.org/bots/api#richblocktable)
     and [InputRichBlockTable](https://core.telegram.org/bots/api#inputrichblocktable)
    .
*   Added the classes [RichBlockExpandableBlockQuotation](https://core.telegram.org/bots/api#richblockexpandableblockquotation)
     and [InputRichBlockExpandableBlockQuotation](https://core.telegram.org/bots/api#inputrichblockexpandableblockquotation)
     representing a block quotation, which can be expanded or collapsed back.
*   Added the classes [RichBlockDocument](https://core.telegram.org/bots/api#richblockdocument)
     and [InputRichBlockDocument](https://core.telegram.org/bots/api#inputrichblockdocument)
    , containing a file.
*   Added support for links of the form `tg://document?id=` for general file uploads in rich messages.

**Ephemeral messages**

*   Added the class [EphemeralMessageParameters](https://core.telegram.org/bots/api#ephemeralmessageparameters)
     and replaced the parameters _receiver_user_id_ and _callback_query_id_ in the methods [sendMessage](https://core.telegram.org/bots/api#sendmessage)
    , [sendAnimation](https://core.telegram.org/bots/api#sendanimation)
    , [sendAudio](https://core.telegram.org/bots/api#sendaudio)
    , [sendDocument](https://core.telegram.org/bots/api#senddocument)
    , [sendLivePhoto](https://core.telegram.org/bots/api#sendlivephoto)
    , [sendPhoto](https://core.telegram.org/bots/api#sendphoto)
    , [sendSticker](https://core.telegram.org/bots/api#sendsticker)
    , [sendVideo](https://core.telegram.org/bots/api#sendvideo)
    , [sendVideoNote](https://core.telegram.org/bots/api#sendvideonote)
    , [sendVoice](https://core.telegram.org/bots/api#sendvoice)
    , [sendContact](https://core.telegram.org/bots/api#sendcontact)
    , [sendLocation](https://core.telegram.org/bots/api#sendlocation)
     and [sendVenue](https://core.telegram.org/bots/api#sendvenue)
     with the parameter _ephemeral_message_parameters_.
*   Added the parameter _ephemeral_message_parameters_ to the method [sendRichMessage](https://core.telegram.org/bots/api#sendrichmessage)
    .
*   Added the field _replace_callback_query_message_ to the class [EphemeralMessageParameters](https://core.telegram.org/bots/api#ephemeralmessageparameters)
    , which allows bots to show an ephemeral message in place of the original message.
*   Supported upload of new files in [editEphemeralMessageMedia](https://core.telegram.org/bots/api#editephemeralmessagemedia)
    .
*   Added the parameter _show_caption_above_media_ to the method [editEphemeralMessageCaption](https://core.telegram.org/bots/api#editephemeralmessagecaption)
    .
*   Added the parameter _rich_message_ to the method [editEphemeralMessageText](https://core.telegram.org/bots/api#editephemeralmessagetext)
    .
*   Added the field _can_send_welcome_messages_ to the classes [ChatAdministratorRights](https://core.telegram.org/bots/api#chatadministratorrights)
     and [ChatMemberAdministrator](https://core.telegram.org/bots/api#chatmemberadministrator)
    .
*   Added the parameter _can_send_welcome_messages_ to the method [promoteChatMember](https://core.telegram.org/bots/api#promotechatmember)
    .

**Reply markup**

*   Added the class [DisabledButton](https://core.telegram.org/bots/api#disabledbutton)
     and the field _disabled_ to the class [InlineKeyboardButton](https://core.telegram.org/bots/api#inlinekeyboardbutton)
    .
*   Added the field _force_reply_ to the classes [InlineKeyboardMarkup](https://core.telegram.org/bots/api#inlinekeyboardmarkup)
     and [ReplyKeyboardMarkup](https://core.telegram.org/bots/api#replykeyboardmarkup)
    .

**General**

*   Added the parameters _can_stop_ and _keep_on_stop_ to the methods [sendMessageDraft](https://core.telegram.org/bots/api#sendmessagedraft)
     and [sendRichMessageDraft](https://core.telegram.org/bots/api#sendrichmessagedraft)
    .
*   Added updates about user stopping message generation, represented by the class [MessageGenerationStopped](https://core.telegram.org/bots/api#messagegenerationstopped)
     and the field _stopped_message_generation_ in the class [Update](https://core.telegram.org/bots/api#update)
    .
*   Added the class [CommunityChatJoined](https://core.telegram.org/bots/api#communitychatjoined)
     and the field _community_chat_joined_ to the class [Message](https://core.telegram.org/bots/api#message)
     for service messages about join of a chat from a community.
*   Added the fields _text_, _entities_ and _is_private_ to the class [UniqueGiftInfo](https://core.telegram.org/bots/api#uniquegiftinfo)
    .
