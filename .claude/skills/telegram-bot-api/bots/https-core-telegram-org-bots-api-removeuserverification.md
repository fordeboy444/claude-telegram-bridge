# \

removeUserVerification\
\
Removes verification from a user who is currently verified [on behalf of the organization](https://telegram.org/verify#third-party-verification)\
 represented by the bot. Returns _True_ on success.\
\
| Parameter | Type | Required | Description |\
| --- | --- | --- | --- |\
| user_id | Integer | Yes | Unique identifier of the target user |\
