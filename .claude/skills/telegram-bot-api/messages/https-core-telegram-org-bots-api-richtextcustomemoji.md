RichTextCustomEmoji\
\
A custom emoji.\
\
| Field | Type | Description |\
| --- | --- | --- |\
| type | String | Type of the rich text, always “custom_emoji” |\
| custom_emoji_id | String | Unique identifier of the custom emoji. Use [getCustomEmojiStickers](https://core.telegram.org/bots/api#getcustomemojistickers)<br> to get full information about the sticker. |\
| alternative_text | String | Alternative emoji for the custom emoji |\
